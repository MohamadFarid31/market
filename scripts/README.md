# اسکریپت‌های اتوماسیون REST API ووکامرس (Market Scripts)

این پوشه شامل اسکریپت‌های Node.js برای ساخت سریع و خودکار ساختار دسته‌بندی‌ها و زیردسته‌ها در هر سایت وردپرسی مبتنی بر ووکامرس است؛ بدون اینکه نیاز باشد ده‌ها دسته و زیردسته را به صورت دستی در پیشخوان تعریف کنید.

---

## ۱. نحوه دریافت کلیدهای REST API در وردپرس (`ck` و `cs`)

1. وارد **پیشخوان وردپرس** سایت مورد نظر شوید.
2. از منوی کناری به مسیر **ووکامرس > پیکربندی** (WooCommerce > Settings) بروید.
3. تب **پیشرفته (Advanced)** را باز کنید و روی زیرمنوی **REST API** کلیک نمایید.
4. دکمه **افزودن کلید (Add key)** یا **ایجاد کلید API** را بزنید:
   - **توضیحات (Description):** مثلاً بنویسید `Category Generator Script`.
   - **کاربر (User):** مدیر کل سایت (Administrator).
   - **دسترسی‌ها (Permissions):** حتماً روی **خواندن/نوشتن (Read/Write)** قرار دهید.
5. دکمه **ایجاد کلید API** را کلیک کنید.
6. در صفحه بعد، دو رشته به شما نمایش داده می‌شود:
   - **کلید مصرف‌کننده (Consumer Key):** رشته‌ای که با `ck_...` شروع می‌شود.
   - **کلید مخفی مصرف‌کننده (Consumer Secret):** رشته‌ای که با `cs_...` شروع می‌شود.
   *(توجه: این کلیدها را کپی کرده و نگه دارید، زیرا کلید مخفی فقط یک‌بار نمایش داده می‌شود).*

---

## ۲. نحوه اجرای اسکریپت

### روش اول: با استفاده از فایل `.env` (ساده‌ترین روش)

1. یک کپی از فایل `.env.example` بگیرید و نام آن را به `.env` تغییر دهید.
2. مقادیر را با اطلاعات سایت خود جایگزین کنید:
   ```env
   WC_SITE_URL=https://your-domain.com
   WC_CONSUMER_KEY=ck_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   WC_CONSUMER_SECRET=cs_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
3. در ترمینال، وارد این پوشه شده و دستور زیر را اجرا کنید:
   ```bash
   node create-categories.js
   ```

### روش دوم: ارسال مستقیم پارامترها در خط فرمان

اگر نمی‌خواهید فایل `.env` بسازید، می‌توانید مستقیماً با آرگومان‌های خط فرمان اسکریپت را اجرا نمایید:

```bash
node create-categories.js --url=https://your-domain.com --ck=ck_xxxx --cs=cs_xxxx
```

---

## ۳. ویژگی‌های اسکریپت (`create-categories.js`)

- **تکرارپذیر و ایمن (Idempotent):** اگر دسته‌ای از قبل روی سایت وجود داشته باشد، دوباره ساخته نمی‌شود و خطایی ایجاد نمی‌کند؛ بلکه شناسه همان دسته موجود را دریافت کرده و زیردسته‌ها را به آن متصل می‌کند.
- **بدون وابستگی خارجی (Zero External Dependencies):** این اسکریپت با Node.js بومی (نسخه ۱۸ به بالا) با استفاده از `fetch` کار می‌کند و نیازی به اجرای `npm install` ندارد.
- **انتقال به سایت‌های دیگر:** در هر سایت وردپرسی جدید، کافیست آدرس و کلیدهای API آن سایت را به اسکریپت بدهید تا کل درخت دسته‌بندی با تمام روابط والد-فرزندی در چند ثانیه ساخته شود.
