# اسکریپت‌های اتوماسیون REST API ووکامرس (Market Scripts)

این پوشه شامل اسکریپت‌های Node.js برای ساخت سریع و خودکار ساختار دسته‌بندی‌ها و زیردسته‌ها در هر سایت وردپرسی مبتنی بر ووکامرس است؛ بدون اینکه نیاز باشد ده‌ها دسته و زیردسته را به صورت دستی در پیشخوان تعریف کنید.

---

## ۱. نحوه دریافت کلیدهای REST API در وردپرس (`ck` و `cs`)

1. وارد **پیشخوان وردپرس** سایت مورد نظر شوید.
2. از منوی کناری به مسیر **ووکامرس > پیکربندی** (WooCommerce > Settings) بروید.
3. تب **پیشرفته (Advanced)** را باز کنید و روی زیرمنوی **REST API** کلیک نمایید.
4. دکمه **افزودن کلید (Add key)** یا **ایجاد کلید API** را بزنید:
   - **توضیحات (Description):** مثلاً بنویسید `Category Generator Script`.
   - **کاربر (User):** مدیر کل سایت (Administrator).
   - **دسترسی‌ها (Permissions):** حتماً روی **خواندن/نوشتن (Read/Write)** قرار دهید.
5. دکمه **ایجاد کلید API** را کلیک کنید.
6. در صفحه بعد، دو رشته به شما نمایش داده می‌شود:
   - **کلید مصرف‌کننده (Consumer Key):** رشته‌ای که با `ck_...` شروع می‌شود.
   - **کلید مخفی مصرف‌کننده (Consumer Secret):** رشته‌ای که با `cs_...` شروع می‌شود.
   *(توجه: این کلیدها را کپی کرده و نگه دارید، زیرا کلید مخفی فقط یک‌بار نمایش داده می‌شود).*

## ۲. نحوه اجرای اسکریپت

### روش اول: با استفاده از فایل `.env` (ساده‌ترین روش)

1. یک کپی از فایل `.env.example` بگیرید و نام آن را به `.env` تغییر دهید.
2. مقادیر را با اطلاعات سایت خود جایگزین کنید:
   ```env
   WC_SITE_URL=https://your-domain.com
   WC_CONSUMER_KEY=ck_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   WC_CONSUMER_SECRET=cs_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
3. در ترمینال، وارد این پوشه شده و دستور زیر را اجرا کنید:
   ```bash
   node create-categories.js
   ```

### روش دوم: ارسال مستقیم پارامترها در خط فرمان

اگر نمی‌خواهید فایل `.env` بسازید، می‌توانید مستقیماً با آرگومان‌های خط فرمان اسکریپت را اجرا نمایید:

```bash
node create-categories.js --url=https://your-domain.com --ck=ck_xxxx --cs=cs_xxxx
```

## ۳. اسکریپت ساخت خودکار محصولات ماک (`create-mock-products.js`)

این اسکریپت به صورت خودکار تمامی دسته‌ها و زیردسته‌های ووکامرس را دریافت کرده و به ازای هر دسته، چند محصول تستی ماک با نام‌گذاری هوشمند، قیمت‌گذاری و وضعیت موجودی تصادفی، و تصویر بندانگشتی ایجاد می‌کند.

### ویژگی‌ها:
- **نام‌گذاری متناسب با دسته:** ترکیب هوشمند نام دسته والد و فرزند همراه با شماره (مثلاً: «اسپیکر ساب ۱۰ شماره ۱»، «اسپیکر ساب ۱۰ شماره ۲»)
- **قیمت‌گذاری و تخفیف تصادفی:** ایجاد قیمت‌های رند و واقع‌گرایانه (به تومان) با اعمال تخفیف شگفت‌انگیز برای حدود ۴۰٪ محصولات
- **وضعیت انبار و موجودی:** تخصیص تصادفی وضعیت «موجود در انبار» (۸۵٪) با تعداد رندوم و «ناموجود» (۱۵٪)
- **تصاویر آزمایشی (Placeholder):** تخصیص تصاویر تستی با پالت‌های رنگی جذاب و مقاوم در برابر خطای آپلود هاست
- **پیوند سلسله‌مراتبی:** اتصال همزمان محصول به زیردسته و دسته والد مربوطه

### دستورهای اجرا:
```bash
# ساخت ۳ محصول به ازای هر دسته (تنظیمات پیش‌فرض با فایل .env)
node create-mock-products.js

# یا از طریق اسکریپت npm:
npm run create-products

# تعیین تعداد دلخواه محصول به ازای هر دسته (مثلاً ۵ عدد):
node create-mock-products.js --count=5

# اجرای شبیه‌سازی بدون ثبت در دیتابیس (Dry Run):
node create-mock-products.js --dry-run

# ساخت فوق سریع بدون دانلود تصویر (مناسب هاست‌های دارای محدودیت اینترنت خارجی):
node create-mock-products.js --no-images

# پاکسازی و حذف تمام محصولات ماک ایجاد شده:
node create-mock-products.js --clean
```

## ۴. اسکریپت همگام‌سازی برگه‌ها (`sync-pages.js`)

این اسکریپت به صورت خودکار تمام برگه‌های مورد نیاز پوسته مارکت را ایجاد کرده، قالب‌های اختصاصی آن‌ها را متصل می‌کند و برگه‌های بلااستفاده پیش‌فرض وردپرس را پاکسازی می‌نماید.

### برگه‌هایی که ساخته و تنظیم می‌شوند:
1. **تماس با ما (`contact-us`):** با قالب `page-templates/page-contact.php` (لینک در هدر و فوتر)
2. **پرسش و پاسخ (`faq`):** با قالب `page-templates/page-faq.php` (لینک در هدر و فوتر)
3. **پیشنهادات و انتقادات (`complaints`):** با قالب `page-templates/page-complaints.php` (لینک در هدر و فوتر)
4. **راهنمای سفارش (`guide`):** با قالب `page-templates/page-guide.php` (لینک در فوتر)
5. **درباره ما (`about-us`):** با قالب `page-templates/page-about.php` (قالب اختصاصی معرفی فروشگاه)
6. **وبلاگ (`blog`):** لینک در فوتر
7. **علاقه‌مندی‌ها (`wishlist`):** لینک دکمه علاقه‌مندی‌ها در هدر

### برگه‌هایی که محافظت می‌شوند (ووکامرس):
- **صفحه اصلی** (`home`)
- **فروشگاه** (`shop`)
- **سبد خرید** (`cart`)
- **تسویه حساب / پرداخت** (`checkout`)
- **حساب کاربری من** (`my-account`)

### برگه‌هایی که پاکسازی می‌شوند:
- **برگه نمونه** (`sample-page`)
- **سیاست حفظ حریم خصوصی** (`privacy-policy`)
- **سیاست مرجوعی و عودت** (`refund_returns`)

### دستور اجرا:
```bash
# اجرای مستقیم با تنظیمات .env
node sync-pages.js

# یا شبیه‌سازی بدون ایجاد تغییرات (Dry Run)
node sync-pages.js --dry-run

# یا با ارسال گذرواژه کاربردی وردپرس (Application Password)
node sync-pages.js --user=admin --pass="xxxx xxxx xxxx xxxx"
```
